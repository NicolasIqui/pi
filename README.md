A5. Abra o CSS do framework (ou inspecione um elemento no DevTools F12). Ele estiliza usando classes ou IDs? Por que você acha que frameworks preferem um dos dois? 

R5: O Bootstrap estiliza seus componentes utilizando majoritariamente classes (exemplos: .d-block e .w-100). Os frameworks preferem classes porque elas são reutilizáveis e podem ser aplicadas simultaneamente a múltiplos elementos em uma mesma página, ao contrário dos IDs, que exigem exclusividade por elemento e restringem a escalabilidade do código.
